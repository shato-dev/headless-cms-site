## A. 作品選定段階

- [ ] 対象作品の著作権ステータスを青空文庫の「図書カード」で確認したか(著作権消滅 / 存続)
- [ ] 翻訳作品の場合、原著者だけでなく訳者の著作権保護期間(死後70年)も確認したか
- [ ] 著作権が存続している作品(著作権者の許諾で公開されているもの)の場合、CCライセンス等の条件(表示・非営利・改変禁止など)を確認し、その範囲内に収まっているか

## B. 要約の中身

- [ ] 原文の言い回しや文構造をそのまま使わず、自分の言葉で書き直されているか(単語を類語に置き換えただけの「言い換え」になっていないか)
- [ ] 要約の構成(章立て・展開の順序)が原作をそのままなぞる「縮小版」になっていないか
- [ ] 要約の長さ・詳細さが、原文を読む代わりになってしまうほど濃くないか(あらすじレベルに留まっているか)

## C. 引用を含む場合

- [ ] 直接引用は必要最小限で、1作品につき使用箇所が限定的か
- [ ] 各引用は短く(目安として一文程度以下)、鍵括弧などで地の文と明確に区別されているか
- [ ] 引用元(作品名・著者名)が明記されているか

## D. 出典・クレジット表示

- [ ] 要約ページに原作品名・著者名(翻訳がある場合は訳者名も)が明記されているか
- [ ] 底本が青空文庫であることを出典として記載しているか(法的義務ではないが望ましい配慮)
- [ ] 「青空文庫」の名称使用が、青空文庫自体の関与・承認を意味するものではないことを踏まえた表記になっているか

## E. 事実確認

- [ ] Claudeが要約中に、原作にない出来事・セリフ・設定を作り出していないか(ハルシネーション確認)
- [ ] 作者名・訳者名・発表年などの書誌情報が正確か

## F. サイト全体のチェック(100作品分)

- [ ] 著作権が存続する作品(ライセンス条件付き)だけを別リスト化し、条件充足を個別に再確認したか
- [ ] サイト全体として、原文の再配布ではなく独自の要約コンテンツとして成立しているか
- [ ] 特定の作品・作者に偏って引用量が多くなっていないか
