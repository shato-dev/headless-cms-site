## D. 出典・クレジット表示(サイト全体の設計への提言)

現在の `aozora-100.json` のフィールド(title / author / author_reading / aozora_card_url /
genre_tags / summary)は、以下を満たすサイトを作る土台として十分:

- 作品名・著者名の明記 → title / author フィールドで対応可能
- 底本(青空文庫)を出典として明記 → aozora_card_url を「出典: 青空文庫」のリンクとして
  各ページに表示する形で対応可能

**サイト実装時に追加で必要な対応**(データではなくテンプレート側の話。M2実装時に反映):

1. 各作品ページに「出典: 青空文庫(リンク)」を明記する
2. サイト全体(フッター等)に「本サイトは青空文庫の作品をもとにした独自の要約を掲載しており、
   青空文庫による公認・監修を受けたものではありません」という趣旨の注記を1箇所置く
3. 小泉八雲の3作品は翻訳者名(田部隆次/戸川明三)も併記するのが望ましい
   (現状 `author` フィールドは原著者名のみ)

## 監査方法(再現性のため)

- 各作品の図書カードURLから、`fetch_aozora.py`(スクラッチパッド内に保存)で本文を取得
  - 図書カードページ自体はUTF-8、リンク先のXHTML本文もUTF-8(取得スクリプトで確認済み)
  - ルビ(`<rt>`/`<rp>`)は除去し、本文のみ抽出
  - 長編は冒頭部分 + 要約中の言及箇所に対応する範囲を重点的に確認
- 100作品を9バッチに分けて並列で本文取得・照合を実施(1回目は実行環境の事故で一部やり直し、
  2回目で完了)
- 各作品ごとに B(言い回し・構成)/ C(引用の正確性)/ E(事実確認)を判定し、問題があれば
  原文の該当箇所を示した上で `要修正` とした
